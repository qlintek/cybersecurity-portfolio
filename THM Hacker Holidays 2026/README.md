# THM Hacker Holidays

This will serve as my folder I will put all the 2026 Hacker Holiday rooms I finish. Hacker Holidays is a free event hosted by THM that provides rooms of various difficulty level in penetration testing to grow skills in red and blue hatting.

I joined the fun a little late, that is why I am not sure if I will be able to finish in time I basically gave myself a week to try to finish the 2 week long series, spoiler one room took me 3 days, others took me 30 minutes. right now I am thinking I am only going to finish the first 10 days. But in the 7 days I have been working on these rooms, working at a break neck speed to try to finish as many as I could I have gone from Social Engineering and prompt injection to fool AI's to researching Zip Slip RCE and successfully delivering an exploitation package that allowed me to surf vulnerable directories.

But throughout the challenge I have learned a lot. I feel like in the course of this last week I have begun to build a routine for reviewing servers for vulnerabilities:

Starting with creating a directory for the investigation, then an nmap directory inside the investigation directory to which I can save my nmap scans. So I can retain a record of system enumeration. moving to reviewing the script revealed to the client with the ability to inspect a page.  

I have been getting to practice using several tools: gobuster, git-dumper, portswigger, foxyproxy, Burp suite, wireshark, and Azure. 

These write ups serve as a proof of my work and experience with all of these tools and a demonstration of my reasoning and problem solving tactics. I also appreciate looking back on this sprint and seeing how far my write ups have matured. I quickly established a repeatable pattern that improves readability, and I began including code blocks and screenshots to better illustrate what is happening in each room.
