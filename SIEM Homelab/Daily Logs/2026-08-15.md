## What I Learned Today
- In VirtualBox "CPUs" refers to the number of Virtual Cores that are exposed for use by a VM.
- Splunk’s enterprise hardware recommendations don’t apply to homelabs; 4 cores + 8GB RAM is appropriate.
- I learned how to integrate an existing VM (Metasploitable) into a new VirtualBox network architecture.

## Commands, Queries, or Configurations Used
- I checked Splunk’s official system requirements and found only enterprise‑grade reference hardware (12GB RAM, 24 vCPU), which is far beyond what a homelab needs.
![alt text](<Photos/2026-08-15/Splunk official System Requirements.png>)
- I decided to find suggestions specifically for a homelab.
